# Responsive Design

## Desktop: 1280px and above

- Full sidebar, utility header, and multi-column workspace.
- Optional contextual AI or activity panel.
- Calendar supports staff/resource columns.
- POS uses category, catalog, and sticky cart columns.
- Tables retain filters and visible primary actions.

## Compact desktop and tablet landscape: 1024px to 1279px

- Collapsible sidebar.
- Context panel moves below the primary workspace or into a drawer.
- Metric cards use two or three columns.
- Calendar preserves touch targets and reduces metadata before reducing width.
- POS remains landscape optimized.

## Tablet portrait: 768px to 1023px

- Overlay navigation.
- Single primary workspace column.
- Secondary panels become drawers or stacked sections.
- Tables use priority columns and accessible horizontal regions where required.
- Calendar defaults to agenda or focused staff view.

## Mobile: below 768px

- Bottom navigation for the five highest-frequency destinations.
- Single-column forms and content.
- Full-screen drawers and sheets.
- Sticky primary actions above safe-area inset.
- Agenda calendar; never a compressed desktop grid.
- No page-level horizontal overflow.
- Financial values wrap or use tabular compact formatting without clipping.

## Required stress states

- 360 by 800 and 390 by 844
- Mobile software keyboard open
- Long customer and service names
- Large currency values
- Empty, loading, error, and permission-denied states
- Dense schedule and empty schedule
- Reduced motion
