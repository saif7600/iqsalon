# Roadmap

1. Foundation: identity, tenancy, organizations, branches, audit, public web and portal shell.
2. Service Catalogue, Staff Profiles, Customer CRM, Resources, and Booking Engine.
3. Point of sale, payments, memberships and commissions.
4. Inventory, purchasing and multi-branch stock.
5. Marketing, notifications, reporting and governed AI employees.

Each phase requires browser, API and persistent-data evidence plus tenant-boundary tests.
